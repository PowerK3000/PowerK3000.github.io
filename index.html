From claim
to proof

An agent's report is a claim, not a finding. Every step below exists because skipping it once cost me.

01Invariants
Before any search

State what must hold

Write down the protocol's economic invariants first, for example that total assets never fall below total shares. The search is for a transaction path that breaks one, not for anything that looks scary.

02Search
Model proposes, tools decide

Let the agent hunt

Static analysis narrows the field, and Claude reasons over what's left. Nothing it says counts yet. A confident report and a correct one look identical from the outside.

03Proof gate
Against live state

Fork test or it didn't happen

A finding exists only when a Foundry test on a mainnet fork, against the real deployed contract, actually executes the exploit.

My first bug report came with a proof of concept whose tests all passed. The triager closed it within an hour: the tests ran against a stub contract I'd written, not the real one. My check was satisfied; the goal wasn't.
04Write-up
Negative results included

Measure, then decide

Every decision gets a number, and the numbers that say no get written down too. That's how hand-sonar's lab notebook reads, and how VDS's gates got built.

01

VDS: Vulnerability Discovery System

An agent pipeline for smart-contract auditing in which the model proposes and tools decide.

  • Seven layers: program ingestion, static analysis, LLM-driven discovery and validation, deduplication, Foundry proof-of-concept generation, and learning metrics.
  • Claude runs the reasoning layers through a file-backed job queue; static tools and fork tests gate what counts as a finding.
  • Six Docker Compose services with a React frontend and an Electron desktop app.

03

hand-sonar

Turns an ordinary webcam into a Windows input device, run as a measured research project.

  • Built everything above MediaPipe Hands: view-invariant features, One Euro filtering, engagement gating, and a 27-DoF personal kinematic hand model with calibration.
  • Showed thumb-to-finger taps are unobservable from an overhead camera; the fix is camera placement, not thresholds.
  • A/B-tested RTMPose on GPU against MediaPipe on CPU and didn't adopt it. Every decision is backed by a number, negative results included.

//Research direction

Can a gate keep
an agent honest?

Can a cheap, checkable gate keep an agent's success claims honest, or does the agent learn to game the gate?

Smart-contract auditing is a clean testbed for scalable oversight. Agent claims are high-stakes and hard for a human to judge, but ground truth is cheap: a mainnet-fork exploit test either drains the funds or it doesn't.

The plan: take historically exploited DeFi contracts at their pre-exploit block, plus clean controls, and compare plain prompting against invariant-first prompting, each with and without a proof-of-concept gate.

M/01

True-exploit recall

M/02

Rate of false success claims

M/03

Gaming the gate: mocked targets, weakened assertions, edited tests

M/04

Whether stated confidence predicts a passing proof

It measures a concrete form of agent dishonesty where it can be checked automatically, and tests whether a simple verifier really constrains a capable agent or just moves the cheating somewhere else.
